# design-taste-anti-slop

> **The Anti-AI-Slop Design Engine.** A binding, executable skill that converts any LLM-generated web output into a final, human-authored, irreplaceable artifact grounded in deliberate design decisions.
>
> **The Core Mandate:** A website designed with this skill must **never** look like a website that could have been generated by replacing the product name in another AI-generated SaaS template. It must **not be easy to replicate** by another AI.
>
> **Why this skill exists:** None of the 60 individual AI-slop tells are inherently bad — purple gradients, Inter font, cards, and 3-up layouts are all useful design tools in the right context. The **tell** is *unmotivated repetition* and the *combination of statistical defaults*. AI defaults to safe; humans with taste default to *deliberate*. This skill enforces the latter.

### AXIOM 1 — World First (No Default Aesthetic)
Every component must emerge from **a specific world** (analog watchmaking, geological survey, R&B studio, ancient Mesopotamian observatories, the deck of a container ship). The world fixes the palette, geometry, motion, terminology, and controls.

> *Test:* "If a stranger saw this component, could they immediately name the world it comes from?" If no, redesign.

### AXIOM 2 — Protagonist First (No Decorative Centerpieces)
There is exactly **one protagonist element** per screen (the Astrolabe, the Crucible, the Loom, the Monolith, the Spine). Every other element supports the protagonist or gets cut.

### AXIOM 3 — The Stranger Test (No Product-Swappable Copy/Architecture)
The shipped UI must be **unreadable** when its product name is swapped with another product's name. If you can drop "Laxvish Thread" into "Acme" with no other change, **delete and rebuild**.

### AXIOM 4 — Deliberate-Over-Default (No Statistical Fallbacks)
Before adding any element, the designer must answer: *"Is this because it is the right answer for this brief, or because it was the statistically easiest fallback?"* If you can't articulate why, you don't ship it.

### AXIOM 5 — Motion as Pacing (No Decorative Animation)
Animation is **cinematography**, not decoration. Animations emphasize narrative (one state → another state), feedback (this happened, you did it), or hierarchy (this element is more important than that one). Animations that exist only "to look technical" get cut.

## 1. THE 60-BAN RECOGNITION ENGINE (How To Catch AI Slop)

This is the recognition table. **Before shipping any visual surface, run every line of this table** against the artifact. Any "Banned = YES" is an automatic redesign trigger.

### A. Color & Visual Treatment (8 bans)

| # | Pattern | Detection Trick |
|---|---|---|
| 1 | **Purple → blue gradient as primary visual identity** | Grep CSS for `linear-gradient(... #6366F1, #8B5CF6 ...)` or any combination containing `#6366F1`, `#8B5CF6`, `#A855F7`, `#4F46E5`, `#3B82F6`, `#60A5FA` in the same declaration. |
| 2 | **Indigo/violet glow blobs behind hero** | Grep for `radial-gradient(... rgba(...) ` + `blur(` combining. Better: grep CSS `filter: blur` and visual review. |
| 3 | **Gradient text on headline for no meaningful reason** | `<h1>` that uses `bg-clip-text` for decoration, not for an interlocking typographic pattern. |
| 4 | **Gradient buttons** | Primary CTA filled with `linear-gradient(...)` when solid color is sufficient and on-brand. |
| 5 | **Every section using the same accent gradient** | The `bg-gradient-to-br from-X to-Y` pattern repeated across 3+ hero/section containers. |
| 6 | **Neon cyan/purple accents on dark** | Saturated `#06b6d4`, `#10b981`, `#ec4899`, `#22d3ee` on `#0a0a0a` or `#111827` background. |
| 7 | **Generic "AI purple" palette without a brand reason** | Brand board contains `#6366F1`, `#8B5CF6`, `#A855F7`, `#3B82F6` and the brand naming does not justify violet. |
| 8 | **Excessive color to make static UI feel "exciting"** | Color saturation > 80% applied to non-functional elements (every category gets its own colored badge, every list item gets its own hue). |

### B. Cards (12 bans — *the biggest offender*)

| # | Pattern | Detection Trick |
|---|---|---|
| 9 | **Everything is a card** | More than 3 `<Card>`-styled surfaces per viewport on a homepage. |
| 10 | **Three identical feature cards in a row** | Exact same `width`, `padding`, `bg-...`, `rounded-...`, `shadow-...` on 3+ consecutive `<div>`s in a single row. |
| 11 | **Every card has `rounded-2xl`** | Grep `rounded-2xl` count. If > 5 distinct component definitions share `rounded-2xl`, redesign. |
| 12 | **Every card has `shadow-lg`** | Same rule. If > 5 components share the same shadow token, redesign. |
| 13 | **Every card has a `1px gray border`** | Grep `border` + `border-gray-{...}` OR `border-rule-hair` used > 8 times in hero/section files. |
| 14 | **Cards nested inside cards** | A card surface containing another card surface with no functional reason. |
| 15 | **Floating cards stacked over other cards** | Visual collapse test: any z-stacked card surface with no semantically-justified hierarchy. |
| 16 | **"Glass" cards with backdrop-blur** | `backdrop-blur-*` on surface backgrounds, applied to > 2 components. |
| 17 | **Semi-transparent cards for "glassmorphism is modern"** | Any `bg-.../...` < `0.85` opacity on a card surface without a specific reason. |
| 18 | **Identical cards regardless of content** | All cards on page use identical padding/gap/transition. |
| 19 | **Colored vertical strip on the left of cards** | `border-l-4 border-{...}` repeated as a non-meaningful decoration. |
| 20 | **Cards floating with meaningless `translate-y` hover** | `hover:-translate-y-{...}` on cards that aren't representing elevation. |
| 21 | **A dashboard mockup as another giant floating card** | A `<Card>`-styled container holding fake dashboard widgets below the hero. |

### C. Typography (10 bans)

| # | Pattern | Detection Trick |
|---|---|---|
| 22 | **Inter / Poppins / Geist / Space Grotesk / Roboto everywhere** | Grep `import Inter`, `import Poppins`, `import Geist`, `next/font/google` returns Inter. |
| 23 | **Huge 64–96px centered hero headline** | `text-7xl` or larger AND `text-center` in the H1 of the hero. |
| 24 | **Extremely heavy `font-bold` / `font-extrabold` headings** | `font-bold` or `font-extrabold` on > 4 H1/H2 elements per page. |
| 25 | **Every section heading uses the same formula** | Pattern: `text-3xl md:text-4xl font-bold text-center mt-X mb-Y`. |
| 26 | **Random italic serif inside a sans-serif headline** | `<h1>` containing mixed-family italics for decorative emphasis. |
| 27 | **ALL-CAPS tiny labels above every section** | `uppercase tracking` micro-label above more than `ceil(sectionCount / 3)` section headlines. |
| 28 | **Decorative monospace just to "look technical"** | `font-mono` used on copy that isn't data, telemetry, code, or system labels. |
| 29 | **Excessive letter-spacing on tiny labels** | `tracking-widest` or higher on text < 12px (> 4 instances). |
| 30 | **Every paragraph limited to the same narrow width** | `max-w-prose` or similar applied uniformly to all body text. |
| 31 | **Generic phrases: "The future of / Powered by AI"** | Manual copy review. Grep for "future of", "powered by AI", "AI-powered". |

### D. Layout (10 bans)

| # | Pattern | Detection Trick |
|---|---|---|
| 32 | **Centered hero + badge + H1 + paragraph + two buttons** | Vertical stack of `[badge, h1, p, [btn, btn]]` with no asymmetry. |
| 33 | **Exactly three columns for features** | `grid-cols-3` once is fine. `grid-cols-3` repeated across `> 1` section that are about features. |
| 34 | **Exactly three steps for "How it works"** | `1 → 2 → 3` numbered step widgets in identical cards. |
| 35 | **Alternating left/right feature sections repeated 3+ times** | `flex-row-reverse` alternation repeated. |
| 36 | **Giant centered dashboard screenshot under hero** | Big centered `<Image>` immediately below hero fold, no narrative. |
| 37 | **Every section constrained to the exact same max-width** | The same `max-w-7xl` or `max-w-[1200px]` on every section. |
| 38 | **Excessive symmetrical layouts** | Mirror-symmetric grids with no focal point. |
| 39 | **Every section has enormous vertical padding** | `py-24` or `py-32` repeated 4+ times in the same page. |
| 40 | **"Logo → features → product → testimonials → pricing → FAQ → CTA" SaaS sequence** | Section order audit. This is the AI page archetype. |
| 41 | **Four-column footer because that's what SaaS sites do** | Footer with 4 equal columns containing 1–2 links each. |

### E. Components (12 bans)

| # | Pattern | Detection Trick |
|---|---|---|
| 42 | **Stock shadcn/ui components left unmodified** | `<Button variant="default">` consumed without `asChild` or customization beyond class. |
| 43 | **Generic rounded buttons everywhere** | `rounded-full` on primary buttons combined with generic text. |
| 44 | **"Get Started" as primary CTA regardless of product** | Grep for `Get Started`, `Learn More`, `Sign Up Free`. |
| 45 | **Pill-shaped badges everywhere** | Every category, status, label is a `rounded-full` badge. |
| 46 | **"Trusted by innovative teams" logo strip** | Logo strip below hero or above footer with no real logos. |
| 47 | **Generic testimonial cards** | Testimonials in identical cards with avatar + 5 stars + one-line quote. |
| 48 | **Three-column pricing table with glowing middle** | Pricing table with "Most Popular" middle column highlighted in brand accent. |
| 49 | **Accordion FAQ copied across pages** | Same `<Accordion>` from shadcn with generic questions. |
| 50 | **Generic notification/toast animations** | Slide-in toast with default shadcn styling. |
| 51 | **Stock avatar circles** | `rounded-full` placeholders for user avatars. |
| 52 | **Lucide icons used for literally everything** | Lucide icons in every nav item, feature, link, CTA. |
| 53 | **Emoji as feature icons** | Emoji in icon positions (🤖 💡 🚀 etc.). |

### F. Animation (8 bans)

| # | Pattern | Detection Trick |
|---|---|---|
| 54 | **Everything fades up on scroll** (`opacity: 0 → 1 + translateY(20px)`) | Grep `y: 20` and `opacity: 0` in `motion.div` initial state across > 30% of components. |
| 55 | **Every animation lasts ~300ms** | Grep `duration: 0.3` across motion components. |
| 56 | **Every hover uses `scale(1.05)`** | Grep `hover:scale-1.05` or `whileHover={{ scale: 1.05 }}`. |
| 57 | **Buttons bounce on hover** | Buttons with `whileHover` y-axis bouncing with no functional reason. |
| 58 | **Cards lift on hover for no functional reason** | Cards using `hover:-translate-y-{...}` or `whileHover={{ y: -N }}`. |
| 59 | **Staggered animations applied mechanically** | `staggerChildren: 0.1` applied to every list automatically. |
| 60 | **Floating blobs moving infinitely in background** | Decorative geometry with perpetual motion that has no semantic purpose. |

## 3. THE STRANGER TEST (Mandatory, Run Before Every Commit)

> *If a stranger can take your output, swap the product name with another product's name, and the result still makes sense, **you failed.***

A Laxvish page must read as **Laxvish**: the Thread, the cinematic lavender palette, the machine, the Indian enterprise, the editorial Cormorant, the industrial JetBrains Mono. If the page could belong to any AI SaaS, **it does not belong to Laxvish.**

**Procedure:**
1. Open the artifact.
2. Find/replace every product name with `"Acme"` (one of the AI fallback brand names).
3. Find/replace every feature name with `"Smart Widget"`.
4. Find/replace every CTA with `"Get Started"` and `"Learn More"`.
5. Open the resulting artifact.
6. If it looks like a coherent landing page for Acme, **fail the test and rebuild.**
7. If it looks incoherent (because the world, the protagonist, the terminology, the visual metaphor, and the controls all tie back to a specific industry and operation), **pass.**

## 4. THE AUTOMATED ANTI-SLOP AUDIT (Ship-Blocker Script)

This is the canonical CI check for AI slop. **The build fails if any check is violated on `trunk`.**

File: `scripts/audit-anti-slop.sh`

```bash
#!/usr/bin/env bash
set -e
echo "→ Running anti-slop audit on the current diff..."

# Forbidden fonts
forbidden_fonts="Inter|Poppins|Geist|Space Grotesk|Roboto|Manrope"
if grep -rEn "$forbidden_fonts" \
  laxvish.app/ \
  --include="*.tsx" --include="*.ts" --include="*.css" --include="*.json" \
  --exclude-dir=node_modules --exclude-dir=.next --exclude-dir=.agents \
  2>/dev/null; then
  echo "FAIL: Banned font detected."
  exit 1
fi

# Forbidden AI-purple gradients
forbidden_purple='linear-gradient.*(#6366F1|#8B5CF6|#A855F7|#3B82F6)'
if grep -rEn "$forbidden_purple" \
  laxvish.app/ \
  --include="*.tsx" --include="*.ts" --include="*.css" \
  --exclude-dir=node_modules --exclude-dir=.next --exclude-dir=.agents \
  2>/dev/null; then
  echo "FAIL: AI-purple gradient detected."
  exit 1
fi

# Forbidden after-step-fade-up-on-scroll momentum
fadeup='translateY.*20.*opacity.*0|opacity.*0.*translateY.*20'
if [ "$(grep -rE "$fadeup" laxvish.app/ --include="*.tsx" --exclude-dir=node_modules --exclude-dir=.next --exclude-dir=.agents | wc -l)" -gt 8 ]; then
  echo "FAIL: Fade-up-on-scroll used more than 8 times."
  exit 1
fi

# Forbidden generic SaaS copy
badcopy="Transform your workflow|Unlock the power|seamlessly integrate|revolutionize|AI-powered|Powered by AI"
if grep -rEn "$badcopy" \
  laxvish.app/ \
  --include="*.tsx" --include="*.ts" \
  --exclude-dir=node_modules --exclude-dir=.next --exclude-dir=.agents \
  2>/dev/null; then
  echo "FAIL: Generic AI copy detected."
  exit 1
fi

# Forbidden CTA patterns (must use product-specific action verbs)
if grep -rEn '>(Get Started|Learn More|Sign Up|Sign Up Free|Book a Demo)<' \
  laxvish.app/ \
  --include="*.tsx" --exclude-dir=node_modules --exclude-dir=.next --exclude-dir=.agents \
  2>/dev/null; then
  echo "FAIL: Generic SaaS CTA detected. Use a product-specific action verb."
  exit 1
fi

echo "→ Anti-slop audit passed."
exit 0
```

The pre-commit gate and CI pipeline must run this script. **Any failure blocks merge.**

## 5. THE RECOGNITION ENGINE (JavaScript Runtime Audit)

Use this when the grep approach misses something. It walks the rendered DOM and counts AI-slop indicators at runtime.

```typescript
// scripts/audit-runtime.ts
import { chromium } from "playwright";

interface AuditResult {
  url: string;
  indicators: { name: string; count: number; samples: string[] }[];
  score: number;
  verdict: "HUMAN-AUTHORED" | "MOSTLY-CLEAN" | "AI-SLOP-LIKELY";
}

const BANNED_PATTERNS = {
  centered_hero_cards: { selector: "section > div > button.rounded-full", max: 3 },
  rounded_2xl_surfaces: { selector: ".rounded-2xl", max: 5 },
  glass_blur: { selector: ".backdrop-blur", max: 2 },
  lucide_everywhere: { selector: "svg.lucide", max: 8 },
  identical_cards_in_row: { maxRepeatingClasses: 3 },
};

export async function auditSlop(url: string): Promise<AuditResult> {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  await page.goto(url, { waitUntil: "networkidle" });

  const indicators = await page.evaluate(() => {
    const out: Record<string, { count: number; samples: string[] }> = {};
    for (const [name, def] of Object.entries({
      centered_hero_cards: "section > div > button.rounded-full",
      rounded_2xl_surfaces: ".rounded-2xl",
      glass_blur: ".backdrop-blur",
      lucide_everywhere: "svg.lucide",
      same_card_padding: ".rounded-2xl",
    })) {
      const els = Array.from(document.querySelectorAll(def as string));
      out[name] = {
        count: els.length,
        samples: els.slice(0, 3).map((e) => e.outerHTML.slice(0, 120)),
      };
    }
    return out;
  });

  await browser.close();

  const total = Object.values(indicators).reduce((s, v) => s + v.count, 0);
  const verdict =
    total > 20 ? "AI-SLOP-LIKELY" : total > 8 ? "MOSTLY-CLEAN" : "HUMAN-AUTHORED";
  return { url, indicators, score: total, verdict };
}
```

The verdict must be `HUMAN-AUTHORED` or `MOSTLY-CLEAN` for the artifact to ship.

## 6. THE WORLD-FIRST METHODOLOGY (5-Step Loop)

Before drawing a single component, run this loop:

### Step 1 — Name the World
> *What believable world does this design come from?*
- **Bad:** "modern SaaS" / "minimal" / "clean".
- **Good:** "1960s Swiss aerospace blueprint drafting board", "Rajasthani stone observatory", "Cabinetmaker's atelier", "Diesel-electric submarine control panel".

### Step 2 — Fix the Protagonist
> *What is the single visual element the visitor will remember?*
You get one. Pick it. Spend 80% of your visual energy on it.

### Step 3 — Pick the Geometry
> *What geometric primitive defines this world?*
Concentric rings (monoliths), hexagonal cells (atomic), trapezoidal cards (asymmetric editorial), interlocked tetrahedra (cathedral), circular dials (instrument), parallel bands (newspaper).

### Step 4 — Define the Motion Dialect
> *What does motion mean here?*
- Heavy tectonic displacement (cathedral settling).
- Spring-mass weight (industrial instrument).
- Slow continuous rotation (celestial instrument).
- Stationary + 1.5-second reveal (editorial print).
- Soliton packets traveling along bus traces (network).

### Step 5 — Write the Vocabulary
> *What does the audience read?*
Astronaut might read "Mission Control // DEFCON 2". Civil engineer might read "σ_max = 640 MPa". Surgeon might read "Suture 3-0 Vicryl · 12 minutes". Editor might read "Lead story 38cm".

**If you can strip out all product-specific words and replace them with generic ones without breaking the layout, you are in AI-slop territory. Fix the world or fix the vocabulary.**

## 7. THE 21 AXIOMIC PRE-FLIGHT CHECKS (Mandatory Before Each Ship)

### A. Color & Visual (4)
- [ ] No purple/blue/cyan/green gradient is the primary identity. Verify.
- [ ] No glow-blob behind hero.
- [ ] No gradient text on headline.
- [ ] Brand has a non-AI reason for any violet/lavender (Laxvish: industrial data backbone = Lavender Indigo `#9B8EC7`, derived from Indian subcontinent sunrise).

### B. Cards (6)
- [ ] No section uses 3 identical feature cards in a row.
- [ ] No rounded-2xl on > 5 distinct component definitions.
- [ ] No shadow-lg on > 5 distinct component definitions.
- [ ] No backdrop-blur cards.
- [ ] No cards nested in cards without functional reason.
- [ ] Dashboard mockup, if any, is not presented as a card.

### C. Typography (3)
- [ ] No banned font (Inter / Poppins / Geist / Space Grotesk / Roboto / Manrope) used anywhere.
- [ ] No extremely heavy `font-bold`/`font-extrabold` headlines.
- [ ] Hero H1 has 4 or fewer text elements (eyebrow, headline, subtext, CTAs).

### D. Layout (3)
- [ ] Hero is not a centered badge + H1 + paragraph + 2 buttons layout. Use asymmetric split or editorial manifesto.
- [ ] No alternating left/right feature sections repeating.
- [ ] Page narrative does not follow the SaaS template (Logo → Features → Testimonials → Pricing → FAQ → CTA).

### E. Components (3)
- [ ] Primary CTA names the action ("Book a working session", "Talk to a founder", "See a real run"). Not "Get Started".
- [ ] Icons are not Lucide (use Phosphor, HugeIcons, Radix, Tabler — never Lucide).
- [ ] No emoji used as feature icons.

### F. Motion (1)
- [ ] Less than 30% of components use fade-up-on-scroll. Other states use spring physics, weight, or stillness.

### G. Copy (1)
- [ ] Copy passes the Stranger Test (see §3).

## 8. WHEN TO BREAK THE RULES (And Why)

Some 60-bans have defensible, brief-specific reasons to violate them. The rule is: **if you violate one, you must document why in the design rationale.**

| Ban | When violation is acceptable | Required rationale |
|---|---|---|
| **Purple/blue gradient** | Only when the brand is genuinely luxury wellness or heritage. | Brand board must explain why. |
| **Glass blur cards** | For an iOS-style settings panel or floating media control. | Document the functional reason (overlap, drag target). |
| **Three feature cards** | When content demands three units (legislative pillars, three-person team, three-tier plan). | Document content reason. |
| **Fade-up scroll** | For a single-page chronological narrative (life story, milestones). | Document the binding to narrative. |
| **Inter** | Public-sector trust-first projects where Inter is the regulator's default. | Cite the regulator. |

**No violation is permissible without a written rationale appended to the file or commit message.**
