# design-taste-frontend-no-slop

> The fundamental problem: the AI is making the design decisions instead of executing design decisions. This skill does not change your taste. It removes the statistical defaults so your taste is what reaches the user.

This skill is a **binding contract**. Before you commit a frontend change — every component, every page, every section — you must walk the 60-item BANNED list and confirm none of the patterns are present. If you find one, you fix it before merging. No exceptions, no "but this is just a quick draft."

---

## HOW TO USE THIS SKILL

1. **Before writing any frontend code**, read this file in full.
2. **During work**, self-audit against the 8 categories. Do not skip categories.
3. **Before committing**, run the Pre-Flight Checklist (end of file). If any item fails, do not commit.
4. **The discipline of the skill is honesty**: this is not about swapping one banned pattern for another from the same statistical cluster. A purple-to-blue gradient replaced with an orange-to-pink gradient is still slop. Reach past the cluster entirely.

## THE 60 BANNED PATTERNS

### A. COLOR & VISUAL TREATMENT (10 bans)

| # | BANNED | WHY |
|---|---|---|
| A1 | Purple → blue gradient as the primary visual identity | Statistical default fingerprint across the entire LLM-era web. |
| A2 | Indigo/violet glow blobs behind the hero | Same default, the blob version. |
| A3 | Gradient text on the main headline for no meaningful reason | Decorative gradient on H1 = template signal. |
| A4 | Gradient buttons (primary CTA) | Stock CTA slop. Solid fills or strokes only. |
| A5 | Every section using the same accent gradient | Indiscriminate gradient reuse. One accent per surface. |
| A6 | Neon cyan/purple accents on dark backgrounds | The "AI dark mode" cliché. |
| A7 | Generic "AI purple" palette without a brand reason | Don't pick purple because it felt safe. |
| A8 | Pure white background + blue/purple accents with no visual character | The other LLM default. No contrast, no texture, no character. |
| A9 | Excessive use of color merely to make static UI feel "exciting" | Color is information. If it's not carrying meaning, it's noise. |
| A10 | One accent color applied indiscriminately to every interactive element | One accent on every button, link, and pill is monotone, not branded. |

**The deeper read:** none of these are inherently bad. A purple gradient, a glass card, or a single accent can absolutely be part of a great product. The tell is **unmotivated repetition and the combination of defaults**. The BANNED list exists because these patterns appear *together* in AI output. Break the cluster.

### B. CARDS — THE BIGGEST OFFENDER (14 bans)

| # | BANNED | WHY |
|---|---|---|
| B1 | Everything is a card | The "card apocalypse." A page with 12 cards is 12 templates stacked. |
| B2 | Three identical feature cards in a row | The single most recognizable AI layout. |
| B3 | Every card has rounded-2xl | Default radius. Mix or use a non-2xl radius. |
| B4 | Every card has shadow-lg | Default elevation. Mix or eliminate. |
| B5 | Every card has a 1px gray border | Default outline. Use hairlines, dotted, or no border. |
| B6 | Every card has identical padding | Visual metronome. Vary density per content. |
| B7 | Cards nested inside cards | Recursive containers. Stop at one. |
| B8 | Floating cards stacked over other cards | Depth theater with no information hierarchy. |
| B9 | "Glass" cards with backdrop-blur | Glassmorphism is a 2023 AI slop signature. |
| B10 | Semi-transparent cards simply because "glassmorphism looks modern" | Same. |
| B11 | Identical cards regardless of content importance | Use card prominence to express hierarchy. |
| B12 | A colored vertical strip on the left of cards | The "category tag" slop. |
| B13 | Cards floating with meaningless translate-y hover animations | Hover for affordance, not for bounce. |
| B14 | A dashboard mockup presented as another giant floating card | SaaS template signal. |

**Replacement discipline:** if a list of items needs to be presented, consider: editorial columns, an asymmetric data table, a numbered list with large numerals, a vertical timeline, in-line prose with a callout, a diagram with labels. Cards are a tool, not a default.

## THE DEEPER PROBLEM (do not miss this)

> Don't make the mistake of thinking: "I'll just remove the purple gradient and use a different font." That won't solve it.

You can make this:

> Inter + purple gradient + 3 cards

into this:

> Manrope + orange gradient + 4 cards

and still produce AI slop. The fundamental problem is that **the AI is making the design decisions instead of executing design decisions**.

That's why a website can be technically excellent, responsive, beautifully coded, and still feel completely soulless. This is a judgment/taste problem, not a coding problem.

**The test:** If a stranger can replace the product name in your output with another product's name and the result looks correct, you failed.

## HOW TO ESCAPE THE DEFAULT CLUSTER

When a brief arrives, do not jump to "I'll use Tailwind + Inter + rounded-2xl + 3-column grid + fade-up." That is the response your training would generate with zero temperature.

Instead, do the **Design Read** first:

1. **What is this product actually for?** Name a specific user, a specific moment, a specific scene. If you cannot, you do not understand the brief.
2. **What would a senior designer reach for here?** Not "what's safe." What would a Director of Design at Linear, Stripe, Apple, Vercel, Pixar, Apple Music, or your favorite reference actually do. Steal the level of intent, not the colors.
3. **What is the ONE thing the user should remember?** If you can name it, the design can be designed. If you can't, the design will be the cluster.
4. **Then pick the system.** Typography, color, grid, motion, components — each is a deliberate choice now, not a default.

## BRAND-COLORED PALETTE DISCIPLINE (no statistical defaults)

If the brand supplies a palette, use it with intent. Do not invent complementary colors that drift toward the statistical cluster.

**Workflow:**
1. **Name the four primary roles** before you write CSS: `surface`, `surface-elevated`, `ink` (body), `mark` (brand accent).
2. **Use one accent for action only.** Not for every link, not for every icon, not for every hover. Action: primary CTA, active state, current selection, status. Nothing else.
3. **Test against the cluster.** If your palette, on its own, could be mistaken for the default LLM cluster (purple/blue/cyan/violet), revise.

## PRE-FLIGHT CHECKLIST (run before commit)

Walk this list. Any "yes" or "not sure" is a block.

- [ ] **A.** No purple/blue gradient, no glow blobs, no gradient text, no gradient buttons. Accent is solid.
- [ ] **B.** No three identical cards in a row. Cards are not the default unit. Mix in tables, columns, lists, diagrams.
- [ ] **C.** Font is chosen because it belongs to the brand, not because it was the default. Headlines are not centered 80px Inter Bold.
- [ ] **D.** Hero is not the centered badge+H1+two-button template. Layout is not the standard SaaS sequence.
- [ ] **E.** Primary CTA is not "Get Started." Secondary is not "Learn More." No Lucide-icon + heading + paragraph repeated.
- [ ] **F.** No fade-up on scroll, no scale(1.05) hover, no floating blobs, no perpetual particle animation.
- [ ] **G.** No 3D glowing AI brain, no abstract orb, no robot face, no generic laptop mockup, no gradient blob replacing a real image.
- [ ] **H.** No "transform / unlock / revolutionize / seamlessly / AI-powered." Copy is specific to this product.
- [ ] **Stranger test.** A stranger cannot replace the product name with another product and have the output still make sense.
- [ ] **Banned-word test.** `grep` for: Inter, Poppins, Geist, Space Grotesk, "Get Started", "Learn More", "Powered by AI", "transform your workflow", "unlock the power", "the future of", "seamlessly integrate", "revolutionize", "AI-powered", "Get started". If any appear in user-facing copy or in the font/component list, justify or remove.
- [ ] **No glass cards, no rounded-2xl on every surface, no shadow-lg on every surface, no 1px gray border on every card.**

If any item fails, fix and re-check. Do not commit slop.
